# v0.2.5 通用换装适配测试版

日期：2026-10-24。本版为本地测试构建，未发布到 GitHub，未进行新的游戏实机验收。

## 改进

新版配置器按换装中的绘制和资源用途分析兼容性，不按角色、作者或固定文件名匹配。
原生网格绘制与临时骨骼提取、菜单绘制分开显示；后两者列为辅助绘制，
不生成触摸包装器，也不再计入普通模型适配失败。
嵌套的自定义辅助着色器及其命令列表继续按临时阶段保守处理。

资源分析支持同一命名空间内的多个 INI、跨命名空间引用和资源别名：

| 情况 | 处理 |
| --- | --- |
| 所选目录中可见的非几何、非计算用途图片缺失 | 提示文件和所在资源；用户确认后可保留原引用继续适配 |
| 索引、顶点、骨骼、计算缓冲区、着色器或 include 缺失 | 阻止写入 |
| 图片文件用于几何或计算绑定 | 按必要资源检查，不能用“允许缺图”跳过 |
| 未引用资源缺失 | 提示，不阻止适配 |
| 自定义模型顶点或几何程序、未知动态范围 | 保守排除，列出原因 |

程序只包装支持的原生索引绘制，保留作者的资源引用、分支与过滤值。
不会把缺失妆容替换成其他脸部贴图，也不会替换或生成缺失的菜单图片。
原 Mod 的缺图和旧解析问题仍需补齐作者素材或另行修复。
资源警告在适配后继续显示；资源新增、删除、大小或修改时间变化会使旧分析失效。
原目录备份和逐字节恢复沿用原协议，已有 `EJ-OUTFIT/1` 包装器无需重新生成。

## 运行时与使用

本版沿用 v0.2.4 的全部十五个运行文件及其原有缓存；没有重编译游戏着色器，
没有新增逐角色规则。Alt 加鼠标左键、默认开启和 Ctrl+Shift+F9 开关行为继续保留。

需要这次通用适配改进的用户，应使用 `drop-in-win64.zip` 中的
`Configurator/EndfieldJiggleConfigurator.exe`，或同版独立包中的配置器。
已安装 v0.2.4 的用户也可单独使用新版配置器选择现有触摸目录。
纯 Mod 包只含运行时，不能单独提供配置器中的换装分析流程。

在换装页选择源目录，分析并勾选支持的绘制后点击“适配所选绘制”。
缺图时确认窗口会列出具体文件；继续后保留作者原引用。
一般写入需要退出游戏与 XXMI；首次升级后完整重启。
不自动扫描并改写所有第三方 Mod，不需要配置器常驻。

## 验证边界

源码增加了不含真实换装资源的回归用例，以及可重复使用的
`Test-OutfitCompatibility.ps1`。测试输入通过参数提供，代码没有登记具体角色或作者。
本地隔离副本中的两份原始换装分别识别出 82、43 处可适配绘制，
以及 10、9 处辅助绘制；原有三处缺图作为警告保留，不再需要预先替换素材。
原 INI 恢复后逐字节相同，非 INI 资源和源目录保持原样。
实际 EFMI 离线加载前后的 23 条既存诊断相同，没有新增解析诊断。

合成回归还覆盖跨命名空间别名、嵌套辅助阶段、资源变更、缺失关键数据、
重复适配拒绝和备份恢复。构建流程执行安装、升级、定位及配置器界面检查。
这不等于游戏中的真实模型拾取、拖动或全部材质组合已经验收，
也不承诺支持未来任意自定义顶点着色器。
