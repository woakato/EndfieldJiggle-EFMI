# v0.2.7c · 官方 XXMI Launcher 独立包（预发布）

v0.2.7c 将官方 XXMI Launcher Portable 2.5.0 直接放入独立包。双击
`Start.cmd` 会打开 `Resources\Bin\XXMI Launcher.exe`。包内包含 EFMI 1.5.1、
XXMI 渲染库 1.3.3 和触摸 Mod；官方 EFMI 配置、核心文件及签名清单保持原样。

本版沿用已测 v0.2.7b 配置器与触摸运行文件。配置器可执行文件的产品版本信息
仍为 `0.2.7b`；本次不重新编译或运行测试。纯 Mod、拖放包和配置器内嵌安装器的
运行文件未变，更新包内说明与归档版本标识。已有 v0.2.7b Release 附件保留不动。

- **已有 XXMI / EFMI**：下载 `EndfieldJiggleEFMI-v0.2.7c-drop-in-win64.zip`。
- **没有 XXMI Launcher**：下载 `EndfieldJiggleEFMI-v0.2.7c-standalone-win64.zip`，
  解压到独立目录并双击 `Start.cmd`。
- **只需要 Mod**：下载 `EndfieldJiggleEFMI-v0.2.7c-win64.zip`。
- 各包 SHA-256 见 `SHA256SUMS-v0.2.7c.txt`。

Alt 镜头隔离、配置器诊断和恢复流程与 v0.2.7b 相同。当前包没有新增游戏内
视觉验收；渲染兼容范围仍以已有说明和实际游戏版本为准。
