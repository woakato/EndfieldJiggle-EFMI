# v0.2.4 大世界触摸与统一 Alt 操作

角色界面与大世界使用同一套触摸操作，保留原来的鼠标抓取与释放逻辑。
本次修订已获用户实机确认可用。

## 更新内容

- 按住 `Alt+鼠标左键` 拖动，松开鼠标左键释放。Alt 可一直按住，再次点击会选择新的位置。
- 同步拾取时的鼠标、视口与按键状态，修复重复点击下方部位仍保留首次上半身抓取位置的问题。
  保留已验证的原始求解器、拾取着色器和 v0.2.3 原皮与换装修复。
- 触摸默认开启，启动时不显示 `TOUCH ON`。配置器默认勾选“启动时开启触摸”，玩家可取消。
- `Ctrl+Shift+F9` 切换开启/关闭，`Ctrl+Shift+F7` 强制关闭，`Ctrl+Shift+F8` 显示/隐藏诊断。
- 同步纯 Mod、drop-in、独立整合版和配置器内嵌安装文件，附带同版源码与 SHA-256 校验文件。

纯 Mod / drop-in 解压为 `EFMI/Mods` 下一个独立目录，让 `shaders` 和运行时 INI 直接位于其中。
独立整合版请完整解压，先打开本包的“等待官方启动”，再通过官方启动器以 DirectX 11 开始游戏。

## 升级

退出游戏，将旧触摸目录备份到 `Mods` 之外，再解压新包并重启游戏。
参数可提前导出后导入；不要用旧 INI 覆盖新版文件。
配置器内置安装器升级会保留旧按键和启动选项；需要新默认操作时，在触摸页点击“默认值”再保存。
已有 `EJ-OUTFIT/1` 换装包装器无需重新适配。

本次输入修订通过 5,760 项合成 GPU 检查；离线检查与用户实机反馈不代表
所有角色、部位、第三方换装或战斗状态均已逐一验证。v0.2.3 与独立诊断包保留供回退和排查。
