## 三种包

- `EndfieldJiggleEFMI-v0.2.7-win64.zip`：现有 EFMI 用的 Mod，附可选 `InputGuard` 程序。
- `EndfieldJiggleEFMI-v0.2.7-drop-in-win64.zip`：同一 Mod、输入模块与内置安装文件的配置器。
- `EndfieldJiggleEFMI-v0.2.7-standalone-win64.zip`：独立启动器、相同 Mod / 输入模块 / 配置器及原始官方库。

前两种包在游戏启动后运行 `InputGuard/EndfieldJiggleInputGuard.exe`，
每次游戏会话启动一次并保持运行；可从多层分类目录向上定位 EFMI。
独立版在 EFMI 就绪后自动启动后台程序，关闭启动器后仍有效。
输入模块使用现有官方加载器，不替换它；基础触摸不依赖输入模块。

按 Esc 可解除隔离，直到松开并重新按住 Alt。切后台时自动解除；
Ctrl / Shift 组合键不触发隔离。按 Alt 前已经按住的鼠标需先释放。
后台程序异常退出后，心跳超时会在 1.5 秒内停止过滤。

Alt 下的游戏鼠标菜单操作也会被过滤，松开 Alt 或按 Esc 后正常操作。
关闭触摸 Mod 不会同步停止输入模块。需要关闭模块时，结束后台程序，
或退出游戏后删除 Mod 下的 `InputGuard` 目录；不再自动加载。

消息拦截、光标分离、释放、焦点变化、Esc 和后台程序失效。

剧情时间 / 自动运镜，以及过场角色是否可拾取。详见
[输入模块说明](https://github.com/woakato/EndfieldJiggle-EFMI/blob/v0.2.7/docs/ALT-INPUT-GUARD.md)。
