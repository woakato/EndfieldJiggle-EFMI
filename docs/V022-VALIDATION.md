# v0.2.2 验证边界

本版补充配置器和拖放包，不更换 v0.2.1 的着色器、缓存或换装运行时桥接。

## 检查范围

- 配置器编译、Mod 库扫描、快捷键冲突分析和 JSON 配置往返。
- 快捷键与参数的非退出模式保存、撤销，保留备份与漂移保护。
- 逐项绘制选择、无效选择拒绝、原目录适配及恢复。
- 内置安装器在隔离 EFMI 中安装和恢复。
- 桌面与紧凑尺寸的五个视图渲染。
- 拖放 ZIP 的目录结构、EXE 完整性和与完整包的一致性。
- EFMI / Mods / 双层触摸目录自动定位、多个启用运行时拒绝、启动器 JSON 路径解析。
- EFMI 总开关与临时原版键位识别，Mod 库和冲突扫描取消。

检查输出保存在构建时的 `reports`，具体结果见随包生成的验证报告。
本文件不代表已登录游戏或验证了实机画面。

## 未验证

- 同一游戏进程内保存设置后按 F10 的触摸与画面表现。
- Ctrl / Shift 触发 EFMI Mods Display 的实机原因。
- 未提供的第三方管理器全局热键、所有换装与自定义顶点阶段。

诊断页按 INI 中的绑定提示潜在冲突，不求值第三方运行条件。
已有安装或运行时版本升级仍需完整退出并重启，不能只用 F10 代替。
程序不向游戏自动发送 F10，不改其它 Mod 的菜单绑定。
