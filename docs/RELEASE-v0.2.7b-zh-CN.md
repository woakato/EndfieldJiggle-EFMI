# v0.2.7b · Alt 拖动与 XXMI 诊断（预发布）

- 按住 Alt 在角色外拖动时，输入模块会固定游戏读取的鼠标位置。Alt＋左键点击使用按下位置，角色触摸仍跟随实际鼠标。正常操作时滚轮可以缩放。Alt 隔离期间屏蔽滚轮，先松 Alt 再松左键时，隔离持续到左键释放。
- 配置器的“按键与诊断”会核对启动器配置指向的 EFMI 和当前所选目录，列出启动器当前选择、EFMI 启用列表状态、输入设置和已记录的部署版本。发现多份配置时，可手动选择本次启动使用的 `XXMI Launcher Config.json`。
- 导出的 JSON 包含 EFMI 加载目录规则、日志时间和可识别的启动器错误类型。复现后保持游戏运行再导出，并说明原版角色是否也无法触摸。报告含本机路径，公开分享前请检查。

**已有 XXMI 的玩家**下载 `drop-in-win64.zip`。退出游戏和 XXMI，把旧触摸 Mod 移到 `Mods` 之外，将新包完整解压到原位置。手动更换使用新包的默认参数，已适配换装可以继续使用。游戏启动后运行 `InputGuard/EndfieldJiggleInputGuard.exe` 使用 Alt 镜头隔离。

**使用独立版的玩家**下载 `standalone-win64.zip`，解压到新目录，按包内说明启动。`win64.zip` 是纯 Mod 包，需要配置器诊断的玩家请选择拖放包或独立版。

本次验证覆盖 Windows 输入、配置器诊断导出和安装恢复。角色外拖动和 UI 点击的游戏内效果待玩家验证。
