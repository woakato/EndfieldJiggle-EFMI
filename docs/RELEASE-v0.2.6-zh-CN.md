# v0.2.6 目录识别修复

2026-11-01 本地测试版，继承 v0.2.5 通用换装适配。

配置器不再依赖 `EndfieldJiggle` 文件夹前缀或固定扫描层数，而是递归查找
EFMI `Mods` 下完整的运行文件，并核对运行时内容。支持分类目录、中文名、
重命名触摸目录和多层嵌套。自动定位 EXE 所在目录时不再限制向上查找层数。

例如以下布局均可识别：

```text
Mods/EndfieldJiggleEFMI-v0.2.6-drop-in-win64/
Mods/功能/EndfieldJiggleEFMI-v0.2.6-drop-in-win64/
Mods/功能/触摸/任意名称/
```

上述最后一层内仍需一起保留 `EndfieldJiggle.ini`、`Passes.ini`、
`Outfits.ini`、`OutfitPreparation.ini`、`shaders` 和可选 `Configurator`。
嵌套目录可以直接改键、改参、适配换装、原位升级和恢复。
升级保留旧参数，备份留在 EFMI 的 `EndfieldJiggleBackups`。

目录名为 `Mods` 的中间分类不再误导换装适配的实际根目录判断。
重命名后的触摸目录不会作为换装列入 Mod 库。
扫描跳过 `DISABLED*` 子树和目录链接；检测到多份启用运行时仍提示冲突。
不自动移动文件，不修改注入器或全局加载配置。

改动在配置器和安装路径逻辑，全部十五个渲染运行文件沿用已接受的 v0.2.4。
旧换装包装器无需重新适配。已有用户可单独使用新版配置器。
手动解压安装时先备份旧版，将完整包放在希望使用的分类路径，勿同时启用新旧两份。

回归覆盖定位、改参、原位升级、设置保留、精确恢复、换装适配与还原、
多份运行时冲突和取消扫描；另以实际 EFMI 加载器检查不同目录布局。
离线加载与游戏内真实拾取、拖动、外观验收分别记录；本版尚无新增实机验收。
本地构建不会修改用户正在使用的 EFMI、游戏或换装目录，也未发布到远端。
