EndfieldJiggle EFMI v0.2.7 独立便携版

首次启动
1. 退出游戏与 XXMI，将整包解压到可写的短目录，例如 D:\EJ。
   不要放进游戏或已有 EFMI 目录，也不要只取出一个 EXE。
2. 打开 EndfieldJiggleLauncher.exe，选择 Endfield.exe，点击“等待官方启动”。
3. 在官方游戏启动器选择 DirectX 11，再启动游戏，等待本包显示就绪。
4. 以后可双击 Start.cmd 开始等待，仍从官方游戏启动器进入游戏。
本包已带 EFMI 与所需运行库，不用另外安装 XXMI Launcher 或 .NET。
一次游戏会话只使用一套 EFMI。启动器就绪后可以关闭。

操作
按住 Alt + 鼠标左键拖动，松开左键释放。触摸默认开启。
Ctrl+Shift+F9 切换触摸，Ctrl+Shift+F7 关闭，Ctrl+Shift+F8 诊断。
输入模块自动后台运行：长按 Alt 隔离鼠标镜头操作，松开恢复，Esc 临时解除。
剧情时间与自动运镜不冻结；Alt 下鼠标菜单也会受影响，松开 Alt 后操作。
结束 EndfieldJiggleInputGuard 后台程序可关闭隔离；游戏退出后模块结束。

配置、换装与修复
从启动器打开配置器可修改参数、管理 Mod 及适配换装，保存后可关闭。
其他换装放进 EFMI/Mods；换装作者要求的额外依赖需自行安装。
不能拖动时，退出游戏及 XXMI，打开配置器“安装与恢复 → 修复目录”，
检查预览后执行。备份保存在 EFMI/EndfieldJiggleBackups。
升级请使用新目录，备份并迁移自己的 Mod 与设置；卸载时退出程序后删除本包。
