# 长按 Alt 隔离镜头鼠标输入

v0.2.7 已转为正式版，使用者确认本次反馈的问题已解决；这不代表所有角色、
剧情或输入设备均已逐一验证。发行包内仅保留简短的 README.txt。

按住 Alt 时，模块屏蔽游戏收到的鼠标移动、点击和滚轮输入。触摸仍使用
Alt＋鼠标左键；松开左键释放触摸，松开 Alt 恢复镜头操作。没有额外的
游戏内开关按键。按 Esc 可立即解除，直到松开并再次按住 Alt。

模块不修改相机矩阵，不暂停游戏、不改时间或动画，也不改变窗口焦点。
因此它不主动冻结剧情自动运镜。剧情脚本是否暂停、过场模型是否走现有
拾取通道、游戏是否使用另一个输入后端，仍需分别实机确认。
它无法阻止剧情脚本、手柄或键盘带来的镜头运动。

## 启动

先通过现有 EFMI / XXMI 启动游戏，然后运行本目录中的
`EndfieldJiggleInputGuard.exe`，并保持它运行。它使用已有的官方
`3dmloader.dll` 加载相邻的输入模块，不替换 EFMI、全局 ShaderFixes、
游戏文件或其他 Mod。请让程序与游戏使用相同权限。
程序会沿自身所在目录向上查找 EFMI，支持分类目录。独立版由启动器
自动启动后台程序，不需要再手动运行；关闭启动器后后台程序继续工作。

程序支持显式传入 EFMI 目录：

```powershell
.\EndfieldJiggleInputGuard.exe 'D:\path\to\EFMI'
```

后台程序退出或异常停止后，过滤会在 1.5 秒内自动失效；游戏切到后台时
也会解除。Ctrl / Shift 组合键不触发隔离。如果按 Alt 前已经按住鼠标，
模块等到鼠标释放后才接管，避免截断已有的游戏拖动。

隔离期间，Alt 相关的游戏鼠标菜单操作也会被屏蔽。需要正常操作这些
菜单时松开 Alt，或先按 Esc 临时解除。关闭触摸 Mod 不会自动退出
输入模块；停止后台程序即可关闭隔离功能。

## 验收与恢复

分别确认大世界、角色界面和剧情中的 Alt 拖动、左键释放、Alt 释放及
Esc 解除；确认滚轮不再缩放、剧情时间和自动运镜继续。离线测试通过
不等于已验证这些场景。不要用一次成功拖动推断所有剧情或角色均支持。

关闭后台程序即可停止过滤。模块代码会保留到本次游戏退出，之后不再
自动加载；删除本目录可移除该可选功能。旧有十五个触摸运行文件保持原样。
