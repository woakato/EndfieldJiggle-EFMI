# 通用渲染通道候选包

2026-10-16 后续状态：用户反馈可以使用，并授权以此运行时替换 v0.2.3 的三个正式包。
下面保留候选包说明；正式包身份和校验值见 PACKAGE-MAP.md。

这是在 v0.2.3 基础上修复其他原皮触摸黑块的纯 Mod 候选包。
v0.2.3 已确认改善汤汤，但用户反馈其他角色仍有黑块，不能将它视为全角色修复。

解压到 EFMI/Mods 下的一个独立目录，目录内直接是 shaders、EndfieldJiggle.ini、
Passes.ini 和 Outfits.ini。不要再套一层 Mods/EndfieldJiggleEFMI。
例如：Mods/EndfieldJiggleEFMI-v0.2.3-native-receiver-candidate-win64/shaders。
用此包替换现有触摸 Mod；保留自己的按键配置时，也可以仅替换 Passes.ini。

新增规则根据共用的蒙皮坐标变换识别渲染通道，保留原有材质指令，
使此前漏掉的颜色、深度和描边变体接收同一个触摸形变。
不需要登记角色名字、模型哈希或顶点数量。旧的拾取、回弹和换装接口保留。
已识别的材质布局同时更新法线和切线；遇到新的输出布局时，
后备规则根据相同坐标变换同步几何，保留该材质原有的法线输出。
规则仍有明确的原生渲染接口边界，不保证未来完全改变结构的着色器自动兼容。

触摸默认关闭：Ctrl+Shift+F8 开关，Shift+左键拖动，Ctrl+Shift+F7 关闭。
请在此前仍出现黑块的原皮上检查开启、拖动及松手回弹，并复查汤汤。
离线顶点和加载检查不能代替这些实际画面验证。

此包不是“无法触摸”诊断包，不包含启动器或配置器。
