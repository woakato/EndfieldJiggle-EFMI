# 换装通用通道修复候选包

2026-10-16 后续状态：配置器已支持新增运行文件，三个完整包已交付，
用户确认可以发布并授权推送到 GitHub。以下保留最初候选包说明；
正式完整包身份、安装方式及校验值见 PACKAGE-MAP.md 和 INSTALL-zh-CN.md。

原皮通用修复后的换装入口仍只识别旧十二道程序，导致新增的颜色、深度或描边
通道在换装替换绘制时收不到同一份触摸位移。本候选包在替换绘制之前按共用
坐标变换识别实例缓冲区，并补齐新原皮颜色程序的换装拾取入口。

## 已装原皮通用修复

退出游戏后，把本包的 `Outfits.ini` 和 `OutfitPreparation.ini` 放进当前触摸
Mod 目录，覆盖旧 `Outfits.ini`，然后完整重启游戏。当前目录应直接包含
`shaders`、`EndfieldJiggle.ini`、`Passes.ini`、`Outfits.ini` 和
`OutfitPreparation.ini`。不要另启用一份完整触摸 Mod。

`Passes.ini` 和其余原皮运行文件保持原皮通用修复 r5 的字节与时间戳。
已有 `EJ-OUTFIT/1` 适配包装器仍使用相同 Begin/End 接口，无需重复适配。
旧配置器不认识新增运行文件；本候选包测试期间先保留现有参数。

## 完整安装

把旧触摸目录备份到 Mods 之外，将本 ZIP 解压为 Mods 下的一个目录。
包根目录直接是 shaders 和 INI，没有第二层 Mod 文件夹。
本包不包含配置器或启动器。默认关闭触摸：Ctrl+Shift+F8 开关，
Shift+鼠标左键拖动，Ctrl+Shift+F7 强制关闭。

## 验证范围

这是换装渲染候选包，尚未经过用户实际画面确认。
检查此前有黑块的换装在触摸关闭、拖动和松手时的表现，并复查同角色原皮。
只适用于使用受支持原生顶点程序的换装，不自动支持自定义顶点着色器。
本包不包含换装模型或纹理，也不是无法触摸诊断包。
