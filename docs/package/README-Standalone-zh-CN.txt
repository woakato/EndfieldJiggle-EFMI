EndfieldJiggle v0.2.7b 独立版（预发布）| 官方 XXMI Launcher 便携版 + 终末地触摸 Mod

整包解压到新的可写短目录，不要覆盖现有 XXMI、游戏目录或 EndfieldJiggle 独立版。
双击 Start.cmd，打开的是 Resources\Bin\XXMI Launcher.exe，也可直接打开该 EXE。
首次使用时在游戏选择页选择《明日方舟：终末地》(EFMI)，确认游戏路径并按界面提示操作。
启动器可以联网检查、安装和更新组件。遇到 VC++ 运行库缺失时，请从微软安装官方 x64 Redistributable。

内含：官方 Launcher 2.5.0、EFMI 1.5.1、XXMI 渲染库 1.3.3，以及 EndfieldJiggle v0.2.7b 拖放版。
EFMI\Mods\EndfieldJiggleEFMI 下已有触摸 Mod，不必再装一份。
Alt 输入隔离和配置器的使用方式请见该目录里的 README.txt。
此包不使用 EndfieldJiggleLauncher.exe，不带个人配置或游戏本体。
