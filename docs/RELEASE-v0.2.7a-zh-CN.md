# v0.2.7a 预发布说明

基于 v0.2.7 正式包 revision 3。只更新 InputGuard 输入 DLL、配置器 EXE、
两种包内 README、独立版清单与源码；保留渲染 INI、着色器、
InputGuard 辅助 EXE、独立版启动器及官方 EFMI 文件。

- 长按 Alt 时继续屏蔽镜头 raw 位移、窗口鼠标移动、右键和滚轮。
  窗口左键事件仍送达 UI；松 Alt 但左键仍按住时继续隔离位移至释放。
- “按键与诊断”页可刷新现场摘要。JSON 导出包含运行布局、
  文件指纹与安装记录匹配、InputGuard 心跳、有限长度的本地日志、
  所选换装的通用资源检查以及单独的 QAQM 适用性和状态检查。
  单项读取失败会保留错误，不会阻止其他部分导出。
- QAQM 不是换装的必要条件。没有 QAQM 引用时报告“不适用”；
  外部换装源目录不被当作当前 EFMI 已加载的证明。

退出游戏及 XXMI 后备份原触摸目录，再完整替换同一包内文件。
纯 Mod 包没有配置器；需要诊断 EXE 请用拖放包或独立版。
不要把不同版本的 Outfits.ini 与 OutfitPreparation.ini 混用。

离线测试覆盖窗口消息、raw 输入、配置器与安装事务，但**尚未在游戏内**
验证屏幕空白处 Alt 左键拖动、Alt 下 UI 点击、先松 Alt 后松左键、
角色界面/大世界/剧情等场景。这是预发布而非已确认的游戏内修复。
诊断报告包含本机路径和日志，公开分享前请脱敏。未进行自动部署。
